Introduction

Autonomous navigation in complex urban scenarios requires a robust interplay between perception, kinematic planning, and high-fidelity control. Simulation environments like CARLA allow for the development and stress-testing of these components under edge-case conditions that are difficult to replicate in the real world.

I developed a full-stack autonomy pipeline that integrates perception-based obstacle detection with a non-holonomic path planner and an MPC (Model Predictive Control) feedback system to achieve smooth, human-like driving behavior.

The Challenge

Creating a useful simulation environment requires addressing the "sim-to-real gap":

"Models trained in simulation often fail in the real world due to differences in sensor noise, physics, and visual appearance."

  • Non-holonomic constraints in tight urban maneuvering
  • High-frequency control loop stability (MPC vs PID)
  • Multi-modal sensor fusion (Lidar + Camera + Radar) via EKF
  • Sim-to-real domain adaptation for perception models
  • Low-latency planning under dynamic agent uncertainty

The Solution

I developed a modular simulation framework with the following components:

  • Hybrid A* Path Planner for kinematically feasible trajectories in constrained spaces
  • Model Predictive Control (MPC) for unified lateral and longitudinal vehicle control
  • Extended Kalman Filter (EKF) for multi-modal sensor fusion and state estimation
  • Semantic Segmentation Backend for robust road and obstacle boundary detection
  • Scenario Runner Integration for automated regression testing of corner cases
